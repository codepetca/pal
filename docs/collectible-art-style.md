# Collectible Art Style

Use this as the canonical base prompt when creating collectible artwork. Append
the specific object brief and technical output requirements after it.

> Icon art style guide: Casual RPG and chibi game UI asset. Chunky proportions, exaggerated soft features, and friendly thick rounded bevels. Clean, smooth hand-painted textures with prominent warm ambient occlusion and high-contrast golden rim lighting. Soft, slightly stylized dark brown outlines, avoiding pure black lines. Vibrant, warm, and highly saturated color palette with a cozy glow. Clean isometric/front-facing 3D perspective, optimized for 2D mobile game icons and collectibles. No photorealism, no gritty textures, and no complex realistic detailing.

Unless an asset brief says otherwise, collectible exports should be 512 × 512
RGBA PNGs with a transparent background, one centered object, a readable
silhouette at 64 × 64, and approximately 8–12% clear space around the object.
Do not add stars, crescent moons, suns, or other celestial symbols as incidental
decoration or as a recurring collection motif. Include symbolic ornament only
when the specific story or object brief explicitly requires it.
